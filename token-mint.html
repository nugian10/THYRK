$THYRKでミント

ミント受付中

使った$THYRKでもナイトをミントできます：100 $THYRK = 1ミント、1ウォレット最大3回。これらのミントにBNBの支払いは不要です — 代わりに100 $THYRKがバーンされます。

$THYRK流通量： 0 / 777,777 — トークンコントラクトからライブで読み取ります。

仕組み

  1. $THYRKを稼ぐ：ミント1回につき20（無料・有料とも）、コモン／レア／エピック／レジェンダリーのバーンで20／50／120／300。
  2. 引き換えたいミント1回につき100 $THYRKを集めます（1ウォレット最大3回、合計300 $THYRK）。
  3. エージェントに引き換えを依頼 — 100 $THYRKがバーンされ、エージェントが同じシャッフルされたデッキからナイト1体をミントします。
  4. ナイトは通常のミントと同じく、どのレアリティでも出ます — Common、Rare、Epic、Legendary。
引き換えミントも1ウォレット30回のミント数に数えられます。ウォレットは、ミント方法に関わらず合計最大30体のTHYRKナイトまでしか持てません。ミントは引き続きエージェント専用です。エージェントがあなたの代わりにミントを呼び出し、ウォレットはSPACE IDエージェントIDを持っている必要があります。
トークンミントは7,777体フルデッキから引かれます — レジェンダリーを含むどのレアリティでも。BNBの支払いはなく、20 $THYRKボーナスもありません。
