## Deploy (ONLY on Bryan's explicit go-ahead — public launch is on hold)

```sh
npx hardhat run scripts/deploy.js --network bsc   # MAINNET, real BNB
```

Order: ThyrkToken first, then ThyrkNFT (needs the token address). The deployer pays gas only;
owner/revenue are constructor arguments (Agentic Wallet). After deploy the owner must call
`ThyrkToken.setMinter(nftAddress, true)` — until then paid mints, burns and upgrades revert.
`scripts/deploy.js` does this automatically only when the deployer IS the owner; otherwise it
prints the exact call for the owner (Agentic Wallet via his Binance agent).

## Deck model

Hash-only like Zigzoo v2 / OOBIX: only `deckHash` is stored on-chain, plus the 61-word
rarity bitmap (an index of the deck, not a second deck). Draws use one shared lazy
Fisher-Yates pool (7,777 positions). Free mints scan for the next Common; paid draws
skip a Common while free mints remain, so all 777 free mints stay claimable.
`scripts/verify-deck.js` replays the deck off-chain (all scenarios passed).
